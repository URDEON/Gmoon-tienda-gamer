CONFIGURACION POSTMAN
---------------------
Usa http://localhost:5050 como base.
Crea un Environment con:

base_url     = http://localhost:5050
access_token = el token recibido al iniciar sesion

Para solicitudes autenticadas usa en Authorization:

Bearer Token
Token: {{access_token}}

Tambien puedes usar el encabezado:
Authorization: Bearer {{access_token}}


LOGIN
-----
POST {{base_url}}/auth/login
Content-Type: application/json

{
  "email": "correo@ejemplo.com",
  "password": "tu-password"
}

La respuesta incluye el campo "token". Copia solo el valor, sin "Bearer".
El login tambien crea una cookie HttpOnly gmoon_refresh.
Postman puede conservarla en su cookie jar para /auth/refresh.


RENOVAR SESION
--------------
POST {{base_url}}/auth/refresh

Sin Authorization y sin body.
La respuesta entrega un nuevo "token". Actualiza access_token en Postman.

Si Postman no envia la cookie, abre Cookies y verifica que localhost tenga
gmoon_refresh. /auth/logout revoca la sesion y elimina la cookie.

ROLES
-----
CLIENTE:
- Compra y consulta solo sus propias boletas.
- Abre /mis-compras.

VENDEDOR:
- Consulta catalogo y boletas.
- No administra usuarios ni crea boletas.
- Abre /vendedor.

ADMIN:
- Administra usuarios, productos y categorias.
- Consulta boletas.
- Crea cuentas CLIENTE y VENDEDOR.
- Abre /admin.


EJEMPLO BOLETA
--------------
POST {{base_url}}/api/v1/boletas
Authorization: Bearer {{access_token}}
Content-Type: application/json

{
  "clienteNombre": "Cliente Gmoon",
  "email": "cliente@ejemplo.com",
  "tipoComprobante": "BOLETA",
  "items": [
    {
      "id": "42",
      "nombre": "Producto existente",
      "cantidad": 1,
      "precioUnitario": 1000
    }
  ]
}

El backend consulta el producto y recalcula precio y total.
La compra es simulada: no cobra ni descuenta stock.
